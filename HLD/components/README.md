# High-Level Design Components

This folder breaks down the core building blocks that show up across most system designs: rate limiters, load balancers, API gateways, caching layers, databases, CDNs, message queues, and similar components—each covered on its own, the way I actually learned them before combining them into full system designs.

Start with [Roadmap.md](Roadmap.md)—it lays out the order to go through these in and links to every file.
